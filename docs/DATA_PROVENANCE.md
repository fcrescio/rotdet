# Training data provenance

The two released candidates were trained from scratch on 4,439 deduplicated
pages from 406 Internet Archive source identifiers. The document-pure
development validation contains 670 pages; the held-out recovery split
contains 789 pages. The split manifest SHA-256 is
`91e1922bbd19fc5ef87e35e7867485004137ecf52e0aebd31d75ff843f9d6c77`.

See [training_sources.json](training_sources.json) for training source
identifiers and links. These references document provenance only: no source
document, scan, OCR text, embedded thumbnail or private evaluation label is
included in the release.

The author treats the Reader Service source pages as upright; training
targets were generated by artificial counterclockwise quarter turns.
Preprocessing is PIL RGB -> grayscale -> square BICUBIC resize -> uint8 ->
artificial rotation -> float32 / 255. Aspect ratio is not preserved.

Recipe: seed 42, AdamW, learning rate 0.0005, weight decay 0.0003, batch
size 32, label smoothing 0.1, gradient clipping 1, cosine schedule over
30 epochs, best development validation checkpoint, patience 12. Each
training page receives one randomly sampled quarter turn per visit;
validation evaluates all four rotations. Variants were trained separately
at their native 256 or 384 resolution, not by resizing a 128 cache.

No explicit license was identified for the source materials. Availability
on Internet Archive does not establish public-domain status or permission
to redistribute. The maintainer considers the training use fair use;
this is the maintainer's position, not a legal determination. Source
references do not grant reuse permission. The code license and any
separately stated weight license do not apply to source documents.

The independent evaluation corpus is separate from training. It includes
private documents and is not redistributed. No dataset repository will be
created for either corpus as part of this release.
